04 / HOW I APPROACH PROBLEMS

Think clearly.
Test step by step.

My approach is to stay calm, understand what is going wrong, and work through possible solutions one step at a time.

01 How I solve a problem ＋

My answer: When I face a problem, I first make sure I understand what is causing it instead of rushing to change things. I break the problem into smaller steps, check the information or error messages available, and try one solution at a time. After making a change, I test it to see if it works and whether it affects anything else. If I still cannot solve it, I research reliable resources or ask someone for guidance. I treat every problem as a chance to learn and improve.

02 Checking a database connection ＋

Approach: Check whether the database service is running, confirm the database name and connection settings, then read the error message and test the connection again.

03 Fixing a website issue ＋

Approach: Reproduce the issue, inspect the relevant code and browser or server errors, make a focused change, and retest the affected page.
