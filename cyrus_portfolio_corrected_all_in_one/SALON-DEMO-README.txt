SALON BOOKING & SERVICE MANAGEMENT SYSTEM — DEMO

Files:
- index.html
- style.css
- script.js

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a browser.
3. Choose a service, complete the appointment form, and submit.
4. Your demo appointment will appear under "My Appointments".

Features:
- Responsive layout and mobile navigation
- Service menu with sample prices and durations
- Booking form with required fields and date validation
- Appointment requests saved in browser localStorage
- Cancel individual requests or clear all demo requests

Important:
This is a front-end learning/demo project. It has no backend, authentication, real stylist availability, email notifications, or server database. Bookings stay in the browser that created them. The sample salon name and prices can be changed.

GitHub:
Create a new repository (for example, salon-booking-demo), upload these three files to its root, then enable GitHub Pages in the repository settings. Use the generated Pages URL as the live demo link.
